# 讲解词源文件

两个位置二选一，不要两边都放：

## 方案 A（推荐）：放进人设包，导入时自动建库

把讲解词放在 `persona/scenic-guide-zh/knowledge/` 下，然后整个目录打包成 `.otpersona` 导入。
导入时会自动创建一个名为「<人设名> Knowledge」的知识库、把所有文件索引进去、并自动绑到这个人设上。
一次操作解决"人设 + 知识库"两件事。

## 方案 B：单独建库

把讲解词放在本目录（`knowledge/`），在 WebUI「资产库 / 知识材料」里建库上传，
或在会话里手动勾选要启用的资料。

---

## 文件规范

```
knowledge/
├── 01-总览.md
├── 02-01-迎客松.md
├── 02-02-观景台.md
└── 03-常见问题.md
```

- **一景点一文件**，文件名用 `序号-景点名.md`，方便在会话里按需勾选。
- 每个文件开头写 **2–3 行结论摘要**，检索命中后模型最可能直接用这段。
- **先结论后细节**，每段不超过 5 行。
- 数字、年代、人名、典故出处要写准；易变信息（票价、时间、场次）后面补「以现场公示为准」。
- 不要放整本 PDF、不要放长表格、不要放宣传软文——噪声大、召回差。
- 单文件控制在 2000 字以内，超了就拆。

## 模板

```markdown
# 迎客松

**一句话结论**：树龄约 1200 年，唐代所植，是本景区标志性古松，位于南门上行 300 米处。

**位置**：南门入园后沿主路直行 300 米，右手边石阶旁。
**看点**：树干六人合抱，树皮呈鳞片状开裂；东侧主枝横伸 8 米，形似展臂迎客。
**传说**：相传为唐代僧人手植，清代县志已有记载。
**实用**：树下有石凳可休息；旺季 9:00–11:00 人最多，建议早上 8 点前或下午 4 点后。
**注意**：树龄与相关数据以景区现场公示牌为准。
```
