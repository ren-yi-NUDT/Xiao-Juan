# 2D 数字人形象方案（讲解员小景）

本项目已把数字人升级为 **2D 分层立绘 + 动作状态机**形态，取代原先的 Wav2Lip 神经口型方案。

## 一、效果

- **全身 2D 动漫形象**：30 岁女性、黑色齐肩短发、黑框眼镜、女士正装+皮鞋、温和干练（你提供的设定）
- **口型**：4 档卡通口型，按语音能量驱动（不是神经口型，这是 2D 图层方案的固有取舍）
- **待机动作**：7 种随机轮播（呼吸眨眼 / 左右张望 / 扶眼镜 / 双手背身后 / 交叠双手 / 重心微调 / 自然垂放）
- **讲解动作**：9 种随机穿插（自然摆手 / 指引 / 欢迎 / 强调 / 思考 / 比大小 / 数数 / 邀请前行 / 点头）
- **关键词触发**：扫描数字人回答文本，命中关键词就做对应动作（如"请看这边"→指引、"欢迎"→挥手、"高达88米"→比大小）
- **按分句切换**：回答按中文标点切分，取最后命中关键词的分句对应的动作，避免话说到一半乱切
- **听你说话时**：显示待机动作（呼吸/眨眼轮播）
- **头部变体**：指引时头转向侧边、思考时歪头

## 二、为什么不用神经口型

神经口型（Wav2Lip）和实时随机动作库是两条不同渲染管线：

| | Wav2Lip | Light2D（本方案） |
|---|---|---|
| 渲染 | 后端 GPU 逐帧推理，输出整帧视频经 WebRTC 推前端 | 纯前端 Canvas 画图层，不占 GPU |
| 动作 | 来自预录视频帧，无法实时随机切换 | 图层切换，天然支持随机/关键词 |
| 口型 | 神经口型（真实） | 4 档卡通口型 |

同一形象无法同时拥有两者。按你的决定，放弃神经口型，换取全身动作能力。旧形象文件和 Wav2Lip 权重都保留在盘上，需要时可切回（见第六节）。

## 四、日常使用

启动（默认已是 mock 轻量模式）：

```powershell
wsl -d Ubuntu -- bash "/mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/00_start.sh"
```

打开 <http://localhost:5173>，形象选「讲解员小景（2D）」，人设选景区讲解员，开始对话。

切换动作/口型参数改 `avatar.json` 的 `extensions` 和 `animation` 段：
- `idle_actions` / `speak_actions`：动作列表
- `keywords`：关键词→动作映射
- `idle_action_period_ms`：待机动作轮换间隔（默认 5000ms）
- `switch_on_sentence_boundary`：是否按分句切换
- `idle_while_user_speaking`：听你说话时是否待机
- `breath_period_ms` / `blink_period_ms`：呼吸/眨眼周期

改完 `avatar.json` 不用重启（前端每次连接重新拉取配置），刷新页面即可。

## 五、换素材 / 改风格

**换形象**：按 `docs/形象分层素材生成Prompt.md` 的规范重新出 27 张图层，按同名覆盖
`examples/avatars/lingshan-guide-2d/light2d/layers/` 里的 PNG 即可，状态和代码都不用改。

**改说话风格**：编辑 `persona/scenic-guide-zh/prompts/style.md`，打包导入人设包：

```powershell
cd "D:\项目\xiao_juan\Xiao-Juan\digital-human\persona\scenic-guide-zh"
Compress-Archive -Path * -DestinationPath "..\scenic-guide-zh.otpersona" -Force
wsl -d Ubuntu -- bash -lc 'curl -s -X POST http://127.0.0.1:8210/personas/import -F "file=@/mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/persona/scenic-guide-zh.otpersona"'
```

**换音色**：当前是 Edge 晓晓。要克隆你自己的声音：把 5–15 秒单人、清晰、无 BGM 的普通话音频放到
`digital-human\素材\` 文件夹，系统用本地 SenseVoice 自动识别文字做校验，再用本地 CosyVoice 复刻，
复刻出的 voice_id 填进 `persona.json` 的 `voice.voice_id` 和 `runtime.tts_provider`。

## 六、切回旧方案（如需）

3. 形象选「动漫讲解员」（Wav2Lip 权重仍在盘上）
