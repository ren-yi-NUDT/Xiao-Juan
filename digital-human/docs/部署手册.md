# 部署手册（本机实测版）

面向：在本机（Windows + WSL2）把 OpenTalking 跑起来，用于景区讲解。
所有命令都在 **WSL Ubuntu 内**执行，PowerShell 里用 `wsl -d Ubuntu -- bash <脚本>` 进入。

---

## 1. 目录约定

| 位置 | 内容 | 原因 |
| --- | --- | --- |
| `~/opentalking-workspace/opentalking` | 源码 + `.venv` | 必须在 WSL 的 ext4 上，放 `/mnt/d` 会慢 5–10 倍且 inotify 失效 |
| `~/opentalking-workspace/models` | 模型权重 | 与源码分离，换版本不重下 |
| `~/opentalking-workspace/model-repos` | OmniRT、CosyVoice 等第三方仓库 | 可选 |
| `~/opentalking-workspace/runtimes` | sidecar venv | 可选 |
| `D:\项目\xiao_juan\Xiao-Juan\digital-human` | 配置 / 脚本 / 你的资产 | 便于 Windows 侧编辑备份 |

---

## 2. 安装

```bash
# 一键：装 uv、克隆源码、后台装依赖
wsl -d Ubuntu -- bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/01_setup_wsl.sh

# 长时间下载用后台版（会清理卡死进程并写 ~/uv_sync.log）
wsl -d Ubuntu -- bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/04_sync_bg.sh

# 查看进度
wsl -d Ubuntu -- bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/99_status.sh
```

手动等价命令：

```bash
cd ~/opentalking-workspace/opentalking
uv sync --extra dev --extra models --extra quicktalk-cuda --python 3.11.9
# 需要本地语音识别（SenseVoice）时再补：
uv sync --extra dev --extra models --extra local-audio --python 3.11.9
```

下载量约 6–8 GB（torch 873 MB + 10 个 nvidia CUDA 包 ≈ 3 GB + triton/onnxruntime ≈ 450 MB + 其余）。
首次装完 `du -sh .venv` 应达到 8–12 GB。

## 3. 启动

```bash
# 阶段 1：Mock（无需权重，先验证 前端/API/LLM/TTS/WebRTC）
wsl -d Ubuntu -- bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/10_start_mock.sh

# 阶段 2：Wav2Lip 真实渲染
wsl -d Ubuntu -- bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/20_prepare_wav2lip.sh
wsl -d Ubuntu -- bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/21_start_wav2lip.sh

# 停止
wsl -d Ubuntu -- bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/98_stop_all.sh
```

- WebUI：<http://localhost:5173>
- API：<http://localhost:8210/health>、<http://localhost:8210/models>
- 日志：`~/opentalking.log`（`tail -f ~/opentalking.log`）

底层启动命令（脚本里就是它）：

```bash
cd ~/opentalking-workspace/opentalking
bash scripts/start_unified.sh --backend local --model wav2lip \
  --env /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/config/env.scenic \
  --api-port 8210 --web-port 5173 --host 0.0.0.0
```

## 4. 权重

### 4.1 Wav2Lip（推荐先用，约 400 MB）

```bash
cd ~/opentalking-workspace/opentalking
mkdir -p ~/opentalking-workspace/models/wav2lip
export HF_ENDPOINT=https://hf-mirror.com
uv run hf download Pypa/wav2lip384 wav2lip384.pth --local-dir ~/opentalking-workspace/models/wav2lip
uv run hf download rippertnt/wav2lip s3fd.pth      --local-dir ~/opentalking-workspace/models/wav2lip
```

目录：

```
models/wav2lip/
  wav2lip384.pth
  s3fd.pth
```

对应 `OPENTALKING_WAV2LIP_MODEL_ROOT=$DIGITAL_HUMAN_HOME/models/wav2lip`。

### 4.2 SenseVoice（本地语音识别，可选）

```bash
cd ~/opentalking-workspace/opentalking
uv run python scripts/download_local_audio_models.py \
  --model sensevoice-small \
  --root ~/opentalking-workspace/models/local-audio
```

模型来自 ModelScope（`iic/SenseVoiceSmall`），约 1 GB。下载后
`OPENTALKING_STT_SENSEVOICE_MODEL_DIR` 指向该目录。

### 4.3 QuickTalk（口型更自然，但权重不随仓库提供）

需要 `checkpoints/` 下四个资产：

```
models/quicktalk/checkpoints/
  quicktalk.pth
  repair.npy
  chinese-hubert-large/pytorch_model.bin
  auxiliary/models/buffalo_l/det_10g.onnx
```

官方文档未给直链，仓库的 `opentalking-download` 只覆盖 FlashTalk / wav2vec。
缺权重时 `/models` 会返回 `local_adapter_missing` 之类的 reason，这时退回 Wav2Lip 即可。

## 5. 8 GB 显存调优

RTX 5060 Laptop 8 GB，驱动 580.88（CUDA 13.0 能力），WSL2 内 GPU 直通正常。

| 参数 | 默认 | 8 GB 建议 | 作用 |
| --- | --- | --- | --- |
| `OPENTALKING_WAV2LIP_MAX_LONG_EDGE` | 832 | 640 | 输出长边，直接决定显存与帧率 |
| `OPENTALKING_WAV2LIP_BATCH_SIZE` | 8 | 4 | 一次合成的帧数 |
| `OPENTALKING_TORCH_DEVICE` | auto | `cuda:0` | 避免误用 CPU |
| 形象分辨率 | 858×1072 | ≤ 640×800 | 素材分辨率越大越吃显存 |

若是 QuickTalk：`OPENTALKING_QUICKTALK_FPS`、`RENDER_CHUNK_MS`、`SLICE_LEN` 都影响显存，
先把模板视频压到 512×640 再试。

查看显存：`nvidia-smi --query-gpu=memory.used,memory.total --format=csv`

> 注意：PyTorch 必须为 CUDA 12.8+ 构建才支持 RTX 50 系（sm_120）。
> 本机装的是 PyPI 默认 wheel（torch 2.10 系列），已验证 `torch.cuda.is_available()` 为 True。
> 如果换了机器出现 `no kernel image is available`，就是 CUDA 版本太旧。

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `uv sync` 卡住十几分钟无进展 | 中途断流，进程停在 futex 等待 | `pkill -f "uv sync"`，清 `~/.cache/uv/.tmp*`，重跑 `04_sync_bg.sh`（缓存会复用） |
| 解析失败 `onnxruntime-gpu requires Python>=3.11` | 上游 `requires-python>=3.10` + 系统 Python 3.11.0rc1 | 已改 `requires-python=">=3.11"` 并用 uv 托管 3.11.9 |
| `ModuleNotFoundError: pydantic_settings` | 没在 `.venv` 里跑 | 用 `uv run ...` 或 `source .venv/bin/activate` |
| 前端 5173 打不开 | `npm ci` 没跑完 / 端口被占 | 看 `~/opentalking.log`；`npm_config_registry` 已指到 npmmirror |
| 浏览器要不到麦克风 | 非 localhost 的 http 不是安全上下文 | 用 `http://localhost:5173`；或 Edge `edge://flags/#unsafely-treat-insecure-origin-as-secure` 加白 |
| `/models` 里 wav2lip 显示不可用 | 权重路径不对 | 确认 `wav2lip384.pth`/`s3fd.pth` 在 `OPENTALKING_WAV2LIP_MODEL_ROOT` 根下 |
| `template_video requires configured allowed frame roots` | OmniRT 侧未配允许目录 | `export OMNIRT_ALLOWED_FRAME_ROOTS="<repo>/examples/avatars"` |
| 新人设/形象导入后看不到 | 目录不在 `OPENTALKING_AVATARS_DIR` 下或没重启 | 重启服务、刷新页面 |
| 讲解时知识库不生效 | embedding 未配或索引未完成 | 检查 `OPENTALKING_AGENT_LIGHTRAG_EMBEDDING_*`；`GET /agent/knowledge-bases/{id}` 看 `indexed` |
| WSL 整体卡死 | 宿主机内存/显存被吃满 | PowerShell `wsl --shutdown` 后重启 |

## 7. 重启与清理

```bash
# 只重启服务
bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/98_stop_all.sh
bash /mnt/d/项目/xiao_juan/Xiao-Juan/digital-human/scripts/21_start_wav2lip.sh

# 彻底重启 WSL（Windows PowerShell）
wsl --shutdown
```

磁盘占用参考：源码 656 MB、`.venv` 约 10 GB、uv 缓存约 6 GB（`uv cache prune` 可清）。
